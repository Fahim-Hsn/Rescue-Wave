=========================================================
RESCUEWAVE - HARDWARE SETUP & DEPLOYMENT INSTRUCTIONS
=========================================================

This document provides a step-by-step guide to configuring the software environment, compiling, and flashing the firmware for all RescueWave ESP32 nodes.

---

## 1. Prerequisites (Software Requirements)

Before uploading any code to the microcontrollers, ensure your development environment is properly configured.

1. Download and install the latest version of Arduino IDE (v2.x recommended).
2. Ensure you have a high-quality Micro-USB or USB-C data cable (some cables only provide power and will not detect the COM port).
3. Install the CP210x or CH340 USB to UART Bridge VCP Drivers (depending on your specific ESP32 board version).

---

## 2. Arduino IDE Setup for ESP32

To program the ESP32 boards, you must add the Espressif ESP32 board package to your Arduino IDE.

1. Open Arduino IDE.
2. Go to **File > Preferences**.
3. Locate the **Additional Boards Manager URLs** field and paste the following link:
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
4. Click **OK**.
5. Go to **Tools > Board > Boards Manager**.
6. Search for **esp32** by Espressif Systems and click **Install**.
7. Once installed, go to **Tools > Board** and select your specific board (e.g., "DOIT ESP32 DEVKIT V1").

---

## 3. Required Libraries Installation

The RescueWave system relies on several external libraries. You must install these via the Arduino Library Manager before compiling the code.

1. Go to **Sketch > Include Library > Manage Libraries**.
2. Search for and install the following exact libraries:
   
   * **LoRa** by Sandeep Mistry (Required for SX1278 RF communication)
   * **Adafruit GFX Library** by Adafruit (Core graphics engine for the Gateway display)
   * **Adafruit ST7735 and ST7789 Library** by Adafruit (Hardware driver for the TFT display)

---

## 4. Flashing the Firmware

Follow these steps for each device (Node-1, Node-2, and Gateway).

1. Connect the ESP32 to your computer.
2. Go to **Tools > Port** and select the active COM port.
3. Open the specific folder for the node you are programming (e.g., `RescueWave_Node2_Sensors`).
4. Double-click the `.ino` file to open it in the IDE.
5. Click the **Upload** button (right arrow icon).
   
> Note: If the Arduino console says "Connecting..." and fails to upload, press and hold the "BOOT" button on the ESP32 board until the flashing process begins.

---

## 5. Serial Monitor Verification

After uploading, you must verify that the node is running correctly.

1. Open the **Serial Monitor** (magnifying glass icon in the top right of the IDE).
2. Set the Baud Rate in the bottom corner to **115200**.
3. Press the "EN" (Reset) button on the ESP32.
4. You should see the initialization messages. 
   * Gateway will show: "Gateway Initialized..."
   * Node-1 will show: "Node-1 (SOS Only) Initialized and Ready..."
   * Node-2 will show: "Node-2 Initialized. Sensors Active."

---

## 6. Critical Hardware Warnings & Troubleshooting

### LoRa Antenna Warning
Never power on the ESP32 while the LoRa module is connected without its antenna attached. Transmitting RF signals without an antenna will reflect the energy back into the SX1278 chip and permanently destroy it.

### Radar Sensor (RCWL-0516) Interference
The microwave radar operates at high frequencies and is extremely sensitive to RF noise generated by the LoRa transmitter. 
* Keep the LoRa antenna at least 10-15 cm away from the radar module.
* If the radar gives false positives or hangs (locks at HIGH), add a 10uF or 100uF electrolytic capacitor across the VIN and GND pins of the radar sensor to stabilize the power drop during LoRa transmission.

### LoRa Power Supply
The SX1278 LoRa module is strictly a 3.3V logic device. Connecting the VCC pin of the LoRa module to the 5V (VIN) pin of the ESP32 will fry the module. Always use the 3.3V pin.

### Synchronization
All nodes share a private network layer defined in the code as `LoRa.setSyncWord(0xF3);`. If you build a new node, this hex value must match across all devices, or the Gateway will ignore the incoming packets.
